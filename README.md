# MITE: Rebuilt

[简体中文](#简体中文)

MITE: Rebuilt is a Forge survival mod for Minecraft Java Edition 1.20.1. It recreates classic MITE survival mechanics and adds optional content.

> **AI disclosure:** This project contains AI-generated content.

## Install

Install Forge **47.4.28** for Minecraft Java Edition **1.20.1** and use Java **17**. Download the mod JAR from the [latest release](https://github.com/K01KA5T3R/MITE-Rebuilt/releases/latest) and put it in the Forge instance's mods folder. Use the same mod version on the client and server. JEI and Inventory Sorter are bundled.

## Build from source

Install JDK 17 and run the Gradle Wrapper from this repository:

| Platform | Command |
| --- | --- |
| Windows | gradlew.bat jarJar |
| Linux / macOS | ./gradlew jarJar |

Gradle writes the build to build/libs. The first build downloads Gradle, Forge and JEI. Published JARs come from the project's verified release process.

## 简体中文

MITE: Rebuilt 是面向 Minecraft Java 版 1.20.1 的 Forge 生存模组，复刻经典 MITE 生存机制，并提供可选的扩展内容。

> **AI 内容声明：**本项目包含 AI 生成内容。

### 安装

请使用 Minecraft Java 版 **1.20.1**、Forge **47.4.28** 和 Java **17**。从[最新发布](https://github.com/K01KA5T3R/MITE-Rebuilt/releases/latest)下载模组 JAR 并放入 Forge 实例的 mods 目录。联机时，客户端和服务端请使用同一模组版本。JAR 已内嵌 JEI 和 Inventory Sorter。

### 从源码构建

安装 JDK 17 后，在仓库根目录运行：

| 系统 | 命令 |
| --- | --- |
| Windows | gradlew.bat jarJar |
| Linux / macOS | ./gradlew jarJar |

Gradle 将产物写入 build/libs。首次构建需要下载 Gradle、Forge 和 JEI。发布页上的 JAR 来自项目已有的验证流程。
